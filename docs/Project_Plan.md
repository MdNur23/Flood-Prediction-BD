# Project Plan

## Final Goal

Publish a high-quality research paper on an AI-based flood prediction system for Bangladesh.

## Timeline

Phase 1: Literature Review
Phase 2: Dataset Collection
Phase 3: Data Preprocessing
Phase 4: Model Development
Phase 5: Model Evaluation
Phase 6: Web Application
Phase 7: Research Paper Writing
Phase 8: Paper Submission

## Required Dataset

- Rainfall Data
- River Water Level Data
- Temperature
- Humidity
- Wind Speed
- Historical Flood Events

## Data Sources

- Bangladesh Meteorological Department (BMD)
- Bangladesh Water Development Board (BWDB)
- Flood Forecasting and Warning Centre (FFWC)
- NASA POWER
